fix: session persistence and OTP login issues in production

Critical fixes for production deployment issues:

Issues Fixed:
1. Session not persisting after login (cookie configuration)
2. OTP verification not creating session

1. Cookie secure=false rejected by browser on HTTPS
2. Cookie sameSite=lax blocked cross-origin requests
3. Cookie domain undefined prevented subdomain sharing
4. OTP verification didn't create session
5. Missing CORS middleware
